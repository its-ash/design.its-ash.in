# Archetype: Content Website

**Covers**: blogs, news sites, documentation portals, knowledge bases.

Build the page as **The Nexus Journal** — a newspaper front page, not a landing page.
No `.hero`, no stat counters, no feature-card grid, no pricing, no testimonials.

Anatomy:

1. **Masthead** (`#hero`) — publication badge on the left; volume, date, and edition in a meta row on the right; rule underneath.
2. **Lead story + rail** (`#features`, `arch-main-aside`) — kicker, oversized article headline (`hero-title arch-headline--article`), standfirst, byline meta (author, role, read time), then 5–6 paragraphs of real prose (`arch-prose`) with h2 crossheads and one pull-quote `blockquote`; save/share buttons after. Sticky aside (`arch-aside`): Latest list, Sections tag cloud, Most Read ordered list.
3. **More from this issue** — article rows (kicker, h3, excerpt, byline meta, section tag) separated by dividers. Rows, not cards.
4. **Documentation Hub** — the only tabs on any archetype: Guides / Reference / Changelog.
5. **From the Archive** — the mandatory slider, framed as evergreen issues.
6. **Write to the Editors** (`#contact`) — the mandatory contact form; subjects: Letter / Pitch / Correction / Docs Feedback.

Signature elements: bylines, read times, prose measure, pull-quote, ordered most-read list.
Tone: literate, editorial, calm.
