# Archetype: Community Website

**Covers**: social networks, forums, Q&A boards, review platforms.

Build the page as **The Forum** — a feed, not a landing page. Rows and people,
not cards and claims.

Anatomy:

1. **Forum bar** (`#hero`) — left: "The Forum" headline over a live meta row (members online, posts today, topics). Right: Search ghost button + "+ New Thread" (opens signup popup). Rule underneath.
2. **Thread feed + rail** (`#features`, `arch-main-aside`) — category tag filter row, then 7 thread rows (`card arch-card-pad arch-row`): initials avatar (`arch-avatar`), bold title, meta line (author · category · replies/views · last reply), status tag (Pinned / Hot / Answered / Review / Unanswered / Open). "Load More" below. Sticky aside: Online Now avatar cluster, Today's Poll (radios + Vote button + result progress bars), Top Contributors ordered list, House Rules card.
3. **Q&A Spotlight** — question card with vote count, then the accepted answer (✓ tag-success + blockquote), then a runner-up answer.
4. **Community Highlights** — the mandatory slider, five milestone moments.
5. **Ask the Moderators** (`#contact`) — the mandatory contact form; categories: Account help / Report / Community call / Appeal.

Signature elements: avatars, reply counts, accepted answer, live poll, leaderboard.
Tone: warm, peer-to-peer, anti-algorithm. No pricing, no counters, no prose essays.
